# Authored retrieval golden sets

Empty on purpose. A golden set that QEVAL1b reports as a measurement goes here, written by
people who maintain this equipment (QEVAL1 question 3): real questions a supervisor or
technician would ask, per equipment class, each naming the library entries a correct
answer must find. It is never written by a model, and never by the model under test.

One file per set, `<class-or-scope>-v<version>.json`, in the format in `../README.md`, with
`"kind": "authored"`. Deepak decides how many questions a set needs before its numbers
are read.
